# Settlement Survival 모드 로드맵

기존 게임의 분위기를 유지하면서 후반 콘텐츠를 늘리고, 남아도는 자원과 활용도가 낮은 자원에 사용처를 만든다. 이 문서는 Settlement Survival 전용이다. 독립 게임 터전(TEOJEON)의 기획은 별도다. 현재 구현·검증 상태는 [개발 인수인계](Development-Handoff.md) 참조.

## 농업 확장

농업 탭의 양봉장 오른쪽 첫 행에 농업연구를 두고, 같은 열에 아래로 총 **5개 연구**를 한 칸씩 배치한다.

| 연구 | 효과 또는 해금 |
|---|---|
| 농업연구 | 재배동 해금, 일반 곡물 재배 현대화 |
| 시설재배 | 유리가 필요한 온실과 과수온실 해금. 과수·특용작물의 시설 재배 |
| 육묘장 | 기존 종묘장과 별개인 실내 나무농장. 산림자원 생산 |
| 산림연구 | 육묘장을 고급 육묘장으로 업그레이드. 대나무·경목 재배 |
| 종자연구 | 고급 육묘장에서 미획득 종자를 선택해 연구하고 획득하는 기능. 고무나무는 후보이며 활용처 미정 |

재배동은 첫 연구의 건물 보상이다. 온실·과수온실보다 면적이 크고 집적화가 낮지만, 일반 밭·과수원보다 재배 여건이 나은 중간 시설로 설계한다. 재배동은 유리보다 낮은 등급의 재료를 사용한다. 각 시설의 작물 목록, 생산량, 크기, 건설비·유지비, 연구 비용·시간은 밸런스 테스트로 정한다. 미획득 종자 선택 UI, 종자 획득 조건, 고급 육묘장 업그레이드는 구현 가능 여부를 먼저 확인한다.

후반 계열 진입 조건으로 **대규모 농장 + 나무 농장**을 제안했다. 두 조건을 충족하기 전에는 첫 노드를 표시하되 잠그고, 가능하면 교차 화살표를 숨긴다. 이 항목은 추후 검증으로 보류했다.

## 후속 모드

| 분야 | 기획 |
|---|---|
| 광업·가공 | 가마·용광로와 강화벽돌·유리·화학연료 생산. 고급 건축자재 및 연료 생산 경로를 만든다. |
| 물류 | 물류연구로 중앙시장·집적창고를 해금한다. 중앙시장은 **별도 12×12 건물**로 공급 범위를 넓히고 종이·밧줄을 유지비로 쓴다. 집적창고는 후반 고밀도 저장시설이며 은을 유지비로 쓰는 방향이다. |
| 무역 | 무역항 개발 후 기존 수상교역소를 국제무역항으로 업그레이드한다. 교역선 왕복시간 단축이 핵심이다. |
| 건설·문화 | 국가문화재를 소·중·대 규모와 한국식 건축을 포함한 세 가지 양식으로 구상한다. 문화재 수리소를 통한 유지관리로 후반 자원 소비처를 만든다. |
| 도로 | 도로 폭 확장과 도로 위계로 도시 계획의 선택지를 늘린다. |

후속 모드의 세부 수치와 연구 연결은 미정이다. 유지비, 교역 왕복시간, 도로 폭, 사용자 선택형 종자 연구처럼 새 동작을 요구하는 항목은 게임 설정이나 코드가 지원하는지 확인한 뒤 구현 범위를 정한다.
