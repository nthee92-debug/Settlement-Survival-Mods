# 개발 인수인계

2026-11-06 기준. 전체 계획은 [모드 로드맵](Mod-Roadmap.md) 참조.

## 현재 상태

- 설치된 모드는 **Agriculture Expansion v0.3.2**. 게임 v1.1.132.97의 새 게임에서 농업연구가 **농업 탭 첫 행, 양봉장 바로 오른쪽**에 나타나는 것을 사용자 스크린샷으로 확인했다.
- 이번 버전에 구현된 연구는 **농업연구 하나**다. 현재 선행 조건은 기존 **농장**(3403)이고 연구 보상은 별도 건물 **재배동**이다. 실제 연구 완료 → 건설 메뉴 노출 → 배치·파종은 아직 검증하지 않았다.
- 화면의 행은 `Position/Int1`, 열은 `Position/Int2`다. 둘 다 0부터 센다. 초기 v0.3의 (6,0)은 화면 아래로 벗어났고, v0.3.1의 (1,0)은 갈대 아래에 표시됐다. v0.3.2의 (0,4)가 최종 확인 위치다. 아래 (1,4)~(4,4)는 후속 네 연구의 자리다.
- 농장 → 농업연구 선이 꺾이는 과정에서 첫 행 아이콘들을 가로지르는 것을 확인했다. 연구 잠금과 선 렌더링을 따로 지정할 수 있는 XML 필드는 아직 확인하지 못했다.
- 향후에는 기존 농장 하나 대신 **대규모 농장과 나무 농장 둘 다**를 선행 조건으로 검토한다. 가능하면 선은 숨기고 잠금 상태와 설명으로 조건을 안내한다. 두 조건의 AND 동작, 난이도별 기술 존재 여부, 선을 숨기는 방법은 보류된 검증 항목이다. v0.3.2에는 반영하지 않았다.

## 재배동 v0.3.2

- 기존 플랜테이션(2026) 모델과 재배 로직을 바탕으로 추가한 별도 건물(910003). 10×8.
- 건설비 임시값은 목재 60(3001), 목판 40(3002), 석재 30(4001). 온실 계열에는 유리를 사용할 계획이다.
- 파종 설정값은 기본 밭 65~180일 대비 55~195일. 작물 허용 목록, 생산 밀도, 실제 파종 가능 기간은 게임 검증 필요.
- 농업연구 ID는 910001. 기본 기술트리 설정 5개에서 선행 조건·건물 해금·건설 메뉴와 한/영 문자열 참조를 검사했다.

## 재현 및 다음 확인

1. Windows Steam의 기본 설치 위치라면 저장소 루트에서 `python -X utf8 Experiments/build-agriculture.py`를 실행한다. 다른 위치라면 스크립트의 `BASE`를 해당 게임의 `StreamingAssets/zipConfig`로 맞춘다.
2. 생성된 `mods/AgricultureExpansion` 폴더를 게임을 종료한 상태에서 `Settlement Survival_Data/MyMods` 아래에 복사한다. 생성기는 설치된 게임 XML을 입력으로 쓰며 이 저장소에는 생성기만 보관한다.
3. 메인 메뉴에서 Agriculture Expansion을 껐다 다시 켜서 게임이 병합 XML을 갱신하게 한다. 새 게임에서 농업 탭을 확인한다. 진단 경로는 게임 데이터 폴더의 `UseMODs/zipConfig` 및 `UseMODs_TMP/zipConfig`다.
4. 먼저 현재판의 농장 연구 전후 잠금 상태와 재배동의 해금·건설·파종을 확인한다. 이후 두 선행 연구와 화살표 표시를 별도로 검증하고 시설재배부터 구현한다.

## 종료한 테스트

중앙시장 반경·저장량, 벌목장·채집소 반경 테스트판은 게임 폴더와 로컬 작업본에서 삭제했고 병합 캐시의 관련 값을 원복했다. 정식 중앙시장은 별도 12×12 건물 기획이다. [테스트 수치와 충돌 기록](https://github.com/nthee92-debug/Settlement-Survival-Mods/issues/1#issuecomment-6682269194).

벌목장 테스트 때 껐던 **Fast And Extra Resource Production**(3464009484)은 마지막 확인 당시 꺼져 있었다. 기존 세이브가 그 모드를 요구한다는 경고가 관찰됐으며, 이는 새 게임의 농업연구 좌표 문제와 별개다.
